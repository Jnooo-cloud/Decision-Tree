Dieses Repository reproduziert die Kursaufgabe "Decision Trees und Random Forests" aus dem Udemy-Kurs "Python fuer Data Science, Machine Learning & Visualization".

## Inhalt

- `3-Decision_Trees_und_Random_Forests.ipynb`: Jupyter-Notebook mit der vollstaendigen Loesung.
- `loan_data.csv`: Datensatz fuer das Beispiel.
- `requirements.txt`: Python-Abhaengigkeiten fuer Binder.

## Ausfuehrung

1. Klicke auf den Binder- oder Colab-Badge.
2. Oeffne das Notebook `3-Decision_Trees_und_Random_Forests.ipynb`, falls es nicht direkt geoeffnet wird.
3. Fuehre alle Zellen der Reihe nach aus.

## Erwartetes Ergebnis

Das Notebook trainiert zunaechst einen Decision-Tree-Classifier und danach einen Random-Forest-Classifier auf dem LendingClub-Datensatz. Am Ende werden fuer beide Modelle Vorhersagen auf den Testdaten erzeugt und als Ergebnis insbesondere ein `classification_report` und eine `confusion_matrix` ausgegeben. Damit laesst sich die Rueckzahlungsprognose fuer Kredite reproduzieren.
